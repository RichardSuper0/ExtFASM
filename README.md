# ExtFASM

ExtFASM is a powerful and comprehensive VS Code extension tailored for **Flat Assembler (FASM 1)**, supporting the **x86-64 (v1-v4)** instruction sets. Built for low-level developers who demand absolute performance and total control over the CPU.

---

## 📥 Download & Install

### Step 1: Download the VSIX package
Click the link below to download the official packaged extension:

👉 **[Download ExtFASM v0.4 (.vsix)](https://github.com)**

### Step 2: Install it in VS Code

#### Method 1: Using the VS Code User Interface (Recommended)
1. Open **VS Code**.
2. Open the **Extensions** view on the left sidebar (`Ctrl+Shift+X` or `Cmd+Shift+X`).
3. Click the **three dots (`...`)** menu in the top-right corner of the Extensions panel.
4. Select **"Install from VSIX..."** from the dropdown list.
5. Browse your local files, select the downloaded `ExtFASM_v0.4.vsix`, and click **Install**.

#### Method 2: Using the Terminal (CLI)
If you are running VS Code or `code-server` through a terminal (such as Termux on Android or a remote Linux host), navigate to your download folder and run:
```bash
code --install-extension ExtFASM_v0.4.vsix
```
*(Note: If you use code-server, change `code` to `code-server`)*.
